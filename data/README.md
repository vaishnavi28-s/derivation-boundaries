# Data

Experiments use the airline domain from RuleArena.

Source: https://github.com/SkyRiver-2000/RuleArena

Clone it alongside this repo:

    git clone https://github.com/SkyRiver-2000/RuleArena.git

The airline problems used are in RuleArena/airline/synthesized_problems/comp_0.jsonl
(first 60 problems). Ground-truth fees are computed by RuleArena's own
compute_answer function.
